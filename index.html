Projets réalisés

QuizMaster — Application de quiz

Application web de quiz interactif. Les questions sont stockées dans une base de données MySQL et tirées aléatoirement à chaque partie. L'interface affiche la question, les choix de réponse et le score en fin de partie. Le projet est hébergé en local via XAMPP.

Technologies : HTML · CSS · PHP · MySQL · XAMPP

ChatRoom — Messagerie commune

Application de chat partagé entre utilisateurs inscrits. Chaque message s'affiche avec le pseudo de l'expéditeur dans une boîte de dialogue commune. Les utilisateurs se connectent avec leur compte pour accéder au fil de discussion.

Technologies : HTML · CSS · PHP · MySQL · XAMPP
